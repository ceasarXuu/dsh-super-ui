# Super UI — 界面字号

DeepSeek Harness（DSH）第三方插件：为**聊天界面以外的界面**提供独立的字号缩放——左右侧边栏、会话顶栏、设置页、插件页、菜单、对话框与提示条。聊天内容继续由官方字号设置控制，因此"读长回答的字号"和"把外壳塞进屏幕"变成两个独立的选择。

| | |
|---|---|
| 包名 | `@ceasarxuu/dsh-super-ui` |
| 宿主要求 | DSH `>=0.2.1-rc.0 <0.3.0`（已在 Desktop 0.2.2-rc.3 实测） |
| 界面位置 | **设置 → 通用 → 界面字号**（紧跟官方「字号大小」行） |
| 其他入口 | `插件 → Super UI → 配置`，或 profile patch 中的 `fontScale`（80–150） |
| 运行时依赖 | 无；浏览器端只使用平台提供的 `react` |
| 许可证 | [MIT](LICENSE) |

## 为什么需要它

官方「字号大小」明确定义为**仅影响会话内容**：它驱动 `--dsh-content-font-size` 与聊天排版阶梯；而侧边栏与设置页的字号写在各自组件 CSS 的字面量里，把聊天字号调大并不会带动外壳。这个插件补上缺失的第二根轴，而不是改动官方那一根：

- `fontScale`（百分比，默认 100）缩放会话列以外的所有字面量界面字号；
- 会话列被重置回出厂字号，聊天正文、工具卡片与输入框完全不受影响；
- 偏好经 Host settings 文档按浏览器持久化，同时可通过 profile patch 与官方插件配置界面编辑。

## 使用

1. 安装本 bundle（**插件 → 添加插件**选择本地目录，或在 profile 的 `cordis.patch.yml` 中登记）。
2. 打开 **设置 → 通用**，使用 **界面字号** 步进器：80–150%，每次 5%，100% 为出厂尺寸，**重置** 回到 100%。
3. 改动立即生效并跨重启保留。`插件 → Super UI → 配置` 里是同一个 `fontScale` 字段，也可以直接写 profile 覆盖：

```yaml
- id: super-ui
  name: '@ceasarxuu/dsh-super-ui'
  config:
    fontScale: 120   # 界面文字放大 20%，聊天不受影响
```

卸载或停用插件会恢复出厂界面字号；缩放本身无需刷新页面，且不会修改 profile 里的其他内容。

## 作用范围

| 随 `fontScale` 缩放 | 不缩放 |
|---|---|
| 左侧边栏（会话树、搜索、底部入口）、右侧边栏外壳 | 会话消息、Markdown、代码块、工具卡片、轨迹视图 |
| 会话顶栏、后台任务列表与顶栏操作 | 输入框、附件、审批/提问接管界面 |
| 设置页、插件管理与市场页、任务页等管理页面 | 官方正文/代码/终端字号设置 |
| 菜单、右键菜单、对话框、提示条、Tooltip | 侧边栏终端单元格字号（仍由官方终端字号设置控制） |

会话内弹出、但挂载到页面 body 的界面（例如从消息里打开的对话框）会跟随界面字号而不是聊天重置——这属于外壳而不是内容，是有意为之。

## 实现原理

1. 一次性遍历所有同源样式表，把字面量 `font-size: <length>` 改写为 `font-size: calc(<length> * var(--dsh-super-ui-scale, 1))`；同一规则里的 `line-height` 只在"该规则同时缩放了字号"时跟随，保证文字行高按比例变化而固定高度/垂直居中的几何不变。
2. 直接原地修改活动的 CSSOM，而不是注入覆盖副本——选择器优先级、`!important`、`@media` 嵌套与规则顺序都与出厂样式表完全一致。
3. 缩放值只是 `<html>` 上一个可继承的自定义属性；会话所在的网格列携带 `--dsh-super-ui-scale: 1`，使其子树内所有 calc() 回到出厂值。
4. MutationObserver 处理启动后才到达的样式表（懒加载客户端模块、插件 HMR）；卸载时逐条恢复被改写的声明。

## 已知限制

- 只改写字面量 `px`/`rem` 字号；`em`、`%` 与关键字仍按继承自然缩放。组件写入的行内 `font-size` 与跨域样式表不处理。
- 不缩放布局几何（图标、内边距、控件高度、侧边栏宽度）——这是字号设置而不是缩放；范围上沿个别固定高度控件可能略显拥挤，80–150% 的区间是刻意保守的。
- `font` 简写只在浏览器接受其中 `calc()` 时缩放（当前 Chromium 支持），否则保持原样。
- 聊天区重置依赖外壳框架结构（右栏列之前的中间网格列）。若未来 DSH 改动框架结构，标记会退化为"全部缩放"：出现视觉退化，但不会抛错。

## 开发

```sh
npm install            # 仅开发期需要 jsdom 跑单元测试
npm run verify         # 语法检查 + node --test test/*.test.mjs
node dev/verify-browser.mjs   # 在无头 Chrome 中渲染 client.js 并断言计算后的字号
```

单元测试覆盖 jsdom 中的 CSSOM 改写、持久化订阅与卸载恢复；`dev/verify-browser.mjs` 覆盖 jsdom 无法计算的部分（真实的 `calc()`/自定义属性解析、会话区重置、后插入样式表），需要 Chromium 内核浏览器（`CHROME=/path/to/chrome` 可覆盖默认查找路径）。
